THE SIX-DIGIT CIPHER: 100 LEVELS OF IQ - quick start
=====================================================
Needs Node.js 20.9 or newer (22 LTS recommended) and npm 10+. No paid APIs. Works offline after install.

WINDOWS (PowerShell)                                  | macOS / LINUX (bash)
------------------------------------------------------|------------------------------------------------------
cd six-digit-cipher                                   | cd six-digit-cipher
npm install                                           | npm install
Copy-Item .env.example .env                           | cp .env.example .env
# put a long random value in AUTH_SECRET (see below)  | # put a long random value in AUTH_SECRET (see below)
npx prisma generate                                   | npx prisma generate
npx prisma migrate deploy                             | npx prisma migrate deploy
npm run db:seed                                       | npm run db:seed
npm run dev                                           | npm run dev

Then open  http://localhost:3000

Generate a secret (any OS):
  node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
Paste it into .env as AUTH_SECRET="..."  (do the same with a second value for DAILY_SALT).

CREATE THE FIRST ADMINISTRATOR (no default password exists)
  npm run admin:create          (asks for email, display name and a password of 12+ characters)
  Sign in at http://localhost:3000/admin/login

OTHER COMMANDS
  npm run validate      Proves all 100 levels: complete data, six-digit string answers, no answer leaks, and EXACTLY ONE
                        solution per level by exhaustive search. Prints exactly which level fails and why.
  npm test              Unit + integration tests (Vitest)
  npm run test:e2e      Browser tests (Playwright). First time:  npx playwright install chromium
  npm run typecheck     TypeScript check
  npm run build         Production build        |   npm start   Run the production build
  npm run levels:build  Regenerate src/data/levels/*.json from scripts/levels/*.mjs (answers come from the solver)
  npm run variants -- --start 2026-11-01 --count 7     Preview/verify daily challenge variants
  npm run levels:import -- file.json                   Import levels (validated, all-or-nothing)

RESET LOCAL DATA
  Windows:      Remove-Item prisma\dev.db*; npx prisma migrate deploy; npm run db:seed
  macOS/Linux:  rm -f prisma/dev.db*; npx prisma migrate deploy; npm run db:seed
  (or: npm run db:reset   - drops, re-migrates and re-seeds)
  Guest progress lives in your browser; clear this site's data (or use Settings > Reset campaign) to wipe it.

TROUBLESHOOTING
  "AUTH_SECRET is missing or too short"  -> set it in .env (32+ characters) and restart npm run dev.
  "Environment variable not found: DATABASE_URL" -> you skipped .env; copy .env.example to .env.
  "No levels are published yet"          -> run npm run db:seed.
  "@prisma/client did not initialize"    -> run npx prisma generate.
  Port 3000 busy                          -> npm run dev -- -p 3001  (and update playwright.config.ts if testing).
  Windows PowerShell blocks scripts       -> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
See README.md for details, security notes and deployment.
